# credit-path

An open-source web app that helps newcomers to the United States understand and build their credit score.

## Planned features
- Credit score simulator (payment history, utilization, credit age, new accounts)
- Credit utilization tracker
- Month-by-month credit-building plan

## Privacy
Users enter only their own data. Everything is stored locally in the browser; no third-party personal data is collected or processed.
